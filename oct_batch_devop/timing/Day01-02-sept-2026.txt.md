- Linux – Operating system used for servers and infrastructure.
- GitHub – Code version control and collaboration.
- Docker – Creates and runs containers.
- AWS – Provides cloud infrastructure and services.
- Kubernetes – Manages and scales containers.
- Helm – Package manager for Kubernetes deployments.
- Terraform – Creates and manages infrastructure using code.
- CI/CD – Automates build, test, and deployment.
- ELK – Collects, searches, and visualizes logs.
- Ansible – Automates server configuration and deployment.
- SSL/TLS – Secures communication using HTTPS.
- SRE – Focuses on system reliability and availability.
- Security Tools – Find vulnerabilities and secure applications.

Domain Name → Human-readable name, e.g. google.com
DNS → Resolves domain name to IP address
IP Address → Logical address for network communication
IPv4 → 32 bits, e.g. 192.168.1.10
IPv6 → 128 bits, e.g. 2001:db8::1
Public IP → Internet-routable
Private IP → Used inside private networks
Internet → Global public network
Intranet → Organization's private network
Subnet → Divides a network into smaller networks; the subnet mask identifies the network and host portions
